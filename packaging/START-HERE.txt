========================================================
 小鸡免费模型  —— 先看这一页
========================================================

【这是什么】

  把你手里各家大模型平台的「免费额度」聚合成一个入口。
  在任意 AI 客户端（WorkBuddy / Cursor / Cherry Studio 等）里
  填一个地址、一个 Key 就能用，网关会自动挑当前最健康的那家。

  服务只监听本机（127.0.0.1），局域网里别人访问不到，不用担心中间被人用。

  注意：本包不含任何 API Key。你得自己去各家免费申请 ——
  申请本身免费、不用绑卡，见下面第三步。


【三步跑起来】

  第 1 步  装 Node.js
     已经装过就跳过。
     没装的话：打开 https://nodejs.org/zh-cn ，下载 LTS 版，
     双击安装，一路「下一步」即可。

  第 2 步  启动
     双击本目录下的  start.bat
     窗口会停留几秒（在启动），然后自己关掉 —— 那就表示网关
     已经在后台跑起来了。

  第 3 步  打开页面
     浏览器访问：http://localhost:8787


【接下来：配一家免费模型】

  页面左上角点「添加供应商」→ 选一家 → 粘贴你自己的 API Key
  → 点「拉取免费模型」。

  免费 Key 去哪申请（都免费，注册即得）：

    · Google AI Studio      aistudio.google.com
    · Groq                  console.groq.com
    · OpenRouter            openrouter.ai
    · 硅基流动               cloud.siliconflow.cn
    · 智谱                  bigmodel.cn

  登录后在控制台里找「API Key / API 密钥」页面，复制出来粘贴即可。

  只配一家也能用。想更稳就多配几家，网关会自动在它们之间切换。


【怎么关掉】

  再双击一次 start.bat，会出现一个菜单，按 2 停止。
  （只关浏览器页面不算停，网关还在后台跑着）


【遇到问题】

  · 页面提示「代理未启动」
      → 你在配置里勾了「走代理」，但本机没开代理软件。
        用不到代理就把那个勾去掉（只有海外厂商才需要）。

  · 提示端口被占用
      → 编辑 config.json，把 port 改成 8788 之类，重启即可。

  · 想知道到底出了什么事
      → 双击 start.bat，选 5 看日志。

  · 路径建议
      → 解压到纯英文路径更省心，比如 D:\xiaoji
