# 测试台

> 本页是 [README](../README.md) 的展开章节。快速开始与项目定位请回 README。

统一入口是 **`test/run-all.cjs`**，改完代码跑这一个就够：

```bash
node test/run-all.cjs            # 离线组（默认；CI 跑的就是这一组）
node test/run-all.cjs --all      # 离线组 + 本机组 + 联网组
node test/run-all.cjs --local    # 只跑需要本机 8787 + Edge 的组
node test/run-all.cjs --online   # 只跑需要真实 Key + 代理的组
node test/run-all.cjs --list     # 只列清单
node test/run-all.cjs protocol   # 只跑文件名含关键词的套件
```

**三组分层**：

- **offline** —— 假上游 / 纯函数 / 本地文件，**零 Key、零网络、零浏览器**。CI 跑的就是这一组
  （本机带目录扫描结果时合计 **517 项**；CI 里没有扫描结果，`model-type-check` 会跳过，实际为 **491 项**）。
- **local** —— 需要**本机 8787 网关在跑** + Edge 浏览器（仪表盘版面与交互），合计 **69 项**。
- **online** —— 需要真实厂商 Key + 代理（端到端打通真实上游）。

> 下表的项数来自最近一次全量运行，仅供参考；**权威项数以 `node test/run-all.cjs` 的实际输出为准**
> （项数会随白名单数据与新增用例浮动，不必为了"对上数字"改文档）。

| `ctx-compact-check.cjs` | 上下文降级 **21 项**（端口 8819/8820）。请求比池里所有模型都大时，网关按实测撞墙规模裁一段历史重发，而不是报"模型不在可用池里"。**重点在反断言**：`system` 消息**绝不许**被删（删了模型不再守指令，比报错更糟）；保留的第一条**绝不许**是 `role:"tool"`（孤立的 tool 消息协议非法，等于把"太大"换成 400）；`tools` 定义**绝不许**被裁（裁了等于客户端以为能调、上游看不到）；小请求**一个字节都不许变**（降级只在"全链嫌大"时触发，不能变成常态路径） |
| `coalesce-retry-check.cjs` | 并发合并 + 限流兜底 **24 项**（端口 8823/8824）。两个"省配额"的机制，重点全在反断言：内容不同的请求**绝不**能被并成一个（那是"给出错误答案"级别）；只差 `temperature` 的也不许合并；流式请求**绝不**合并（流式热路径历史上出过三次事故）；长 `Retry-After` **绝不**去等（让用户白等 5 秒再报错，比立刻报错更糟）；两个开关关掉后行为必须与改动前完全一致。⚠ 计数按**第一条消息内容**当标记，不按模型名 —— 网关启动 3 秒后的目录刷新会打到同一个模型上，按模型名计数会让"上游只被打 1 次"这类断言随机抖动（实测同一用例两次跑出 3 次和 4 次） |
| `fail-scope-check.cjs` | 失败归类的**作用范围** + 连续失败退避 **15 项**（端口 8825/8826）。① 免费池里常见的 401/403 其实是"这个模型只对某些客户端/付费档开放"，与 Key 好坏无关；误判成 `auth` 会把**整把 Key 冷却 10 分钟**，一家 17 个模型里 16 个本来能用的被连坐。断言：该模型进 `blocked`、`keyCooldown` 仍为空、`cooldownUntil` 不在未来、同家兄弟模型照常 200、第二次调用直接 404 **不打上游**。② 固定冷却挡不住真坏的模型（冷却到期准时回到队列、再白等一个往返，循环到天荒地老），改为按连续失败次数翻倍，成功一次立刻清零。⚠ **两个分支都要测**：`503 "service unavailable"` 归 `server`（90s 起），`503 "overloaded"` 归 `overloaded`（60s 起，是**另一个分支**）—— 只测前者会漏掉"改了一个分支以为覆盖全部"这类事故。⚠ 读的是 `/api/state`（内存态）而不是 `config.json` —— `saveConfig` 有 300ms 防抖，写完立刻读盘读到的是上一轮的旧值，断言会假红；"到底落盘了没有"另有一条独立断言 |
| `fail-path-check.cjs` | 三条"失败路径"上的体验修复 **20 项**（端口 8827/8828；8829/8830 是**故意不监听**的死端口）。① **额度重置按厂商自己的时区**：openrouter 的 `free-models-per-day` 是 **UTC 零点**，旧代码一律按 UTC+8 算 → 额度早回来了我们还在冷却，最多白等 8 小时。断言两家对同一条错误算出**不同**的重置时间（这条防"改了个参数但其实没生效"）。② **"代理没开"不是厂商的错**：旧行为当 `network` → 整家冷却 90 秒，用户打开代理后还要再等 90 秒。现在只冷却 5 秒，且**不动** `downUntil` / `failStreak` / 质量统计。反断言：**直连**连不上仍是 90 秒整家冷却（别把正常通道一起改坏）。③ **首字节超时"有退路才敢早放弃"**：链上还有别的候选、且该模型有 ≥3 个实测样本时，按它**自己的**常态 TTFB 收紧到 6 秒级；它是最后一个候选时保持 15 秒（早放弃只会把"慢一点但能答"变成"报错"）。⚠ 超时值只能从 `/api/usage` 的失败记账里读到 —— 它不出现在成功响应体里 |
| `startup-files-check.cjs` | 启动入口不变式 **14 项**。`小鸡开关.bat` / `xiaoji-launcher.vbs` 必须**全 CRLF、无 BOM、纯 ASCII**（这三条以前只写在文档里、**没有任何断言** —— 而 bat 被静默改成 LF 那次就是靠字节级统计才发现的）；外加 `.gitattributes` 里两条 `eol=crlf` 规则仍在、且**排在通配规则之后**（git 后出现者生效，顺序反了会被静默盖掉） |
| `key-rotate-check.cjs` | 多 Key 轮转（LRU）**6 项**（端口 8831/8832）。`pickKeyIdx()` 是唯一决定"这次花哪把 Key 的额度"的地方，旧实现是"从下标 0 往后找第一把没冷却的"= **永远用第 0 把**：配了 3 把却只用 1 把，等于把 3 份额度当 1 份花，而且切换点是"第 1 把已被限流(429)"，那次请求已经白费。断言：3 把 Key 连打 4 次 → 假上游看到的 Authorization 依次 `a,b,c,a`；**任何一把不许被连续用两次**（旧实现在这条上必红，这是本套件的核心判据）；新加的 Key（`lastUsed` 为空）必须优先；删到只剩一把时每次都选它（不能返回 `-1`，否则上游收到空 Key 直接 401）。⚠ 沙箱里 `coalesce` 必须关掉：默认开启的并发合并会把"同时在飞的相同 payload"并成一次，第 2、3 次根本不产生上游请求 |
| `wl-freshness-check.cjs` | 白名单"变没变"的判据 **11 项**（端口 8833，全程离线：三个真实源被桩掉，行为由 `FAKE_VER`/`FAKE_MODE` 控制）。同步间隔从 6 小时提到 30 分钟后，这个判据成了实时机制的地基，**判错两个方向都不报错**：把"没变"判成"变了"→ 每 30 分钟重建 hosts 并连带扫一遍所有已接入厂商；把"变了"判成"没变"→ 名单**永远不再更新**。锁三条：① 上游回 304 → 判没变；② 回 200 但**正文指纹相同** → 判没变（OpenRouter 的真实情形：791KB + `max-age=120`，`Last-Modified` 每 2~4 分钟就变，30 分钟后带 `If-Modified-Since` 几乎必然拿到 200）；③ 正文真变了 → 必须重建（反断言，防止短路写成"永远短路"；已用错误判据实测 2 红）。 |
